# دليل الديمو — About / وحدة التحكم

افتحي التطبيق → About.
فوق: خط الأنابيب (سبعة مربعات).
تحت: أزرار السيناريوهات.
تحت أكثر: سجل التدقيق.

---

## قبل ما تضغطين أي زر

قولي للجنة:
> This is the live workflow. Not the video. When I press a button, the steps light up and the log shows what ran.

---

## الزر 1 — الحالة العادية (SC-01)

**الاسم على الشاشة (بعد التحديث):**
- عربي: حالة عادية — جواب بمصادر رسمية (SC-01)
- إنجليزي: Normal case — answer backed by official sources (SC-01)

**وش يصير داخلياً:** يسجّل أن المساعد جاوب على سؤال التوفير من قاعدة المعرفة. (الجواب الكامل تشوفينه في شاشة المساعد.)

**وش يظهر بعد الضغط:**
- زر يصير "تم"
- سطر في السجل تقريباً: `مساعد المعرفة: SC-01 — سؤال عن توفير فاتورة الكهرباء`

**قولي أثناء الضغط:**
> Normal case. User asks how to save on the bill. We answer from official sources.

**لو حبوا يشوفون الجواب نفسه:** روحوا شاشة المساعد واكتبوا: كيف أوفر في فاتورة الكهرباء؟

---

## الزر 2 — يوم عداد ناقص (SC-02)

**الاسم على الشاشة:**
- عربي: يوم عداد ناقص — النظام يكمّل الفجوة (SC-02)
- إنجليزي: Missing meter day — system fills the gap (SC-02)

**وش يصير داخلياً:** يحط سلسلة أيام وفيها يوم 4 فاضي، ثم المعالج يعبّي الرقم الناقص عشان التوقع ما يوقف.

**وش يظهر بعد الضغط:**
- مربعات المصدر والمعالج تضيء (أخضر)
- سطر في السجل تقريباً: `المصدر: SC-02 — سلسلة يومية فيها يوم ناقص`
- سطر ثاني تقريباً: `المعالج: عبّينا اليوم الناقص — يوم 4 صار رقم استهلاك`

**قولي أثناء الضغط:**
> One meter day is missing. The clean step fills it. The forecast continues. No crash.

---

## الزر 3 — طلب إعلانات (SC-03)

**الاسم على الشاشة:**
- عربي: طلب إعلانات — النظام يمنعه (SC-03)
- إنجليزي: Ads request — system blocks it (SC-03)

**وش يصير داخلياً:** طلب وهمي يستخدم بيانات الاستهلاك للإعلانات → عقدة السياسة ترجع مخالفة وتمنع الاستخدام.

**وش يظهر بعد الضغط:**
- مربع السياسة يصير أحمر (محجوب)
- سطر في السجل تقريباً: `حارس السياسة: مخالفة — منع استخدام البيانات للإعلانات`
- غالباً يظهر تنبيه في التطبيق عن منع الإعلانات

**قولي أثناء الضغط:**
> Someone asks to use power-use data for ads. The policy step blocks it.

---

## الزر 4 — موجة حر (اختياري، لا تضغطينه إلا إذا طلبوا)

**الاسم:** موجة حر — سيناريو كامل / Heatwave — full scenario

**وش يصير:** يرفع الحرارة، يزيد الاستهلاك، يشغّل التوقع، ويختبر حجب الإعلانات مرة ثانية.

**قولي فقط إذا سألوا:**
> This runs the full summer stress path in one click. The three main evaluation cases are the first three buttons.

## كيف تقرأين سجل التدقيق (بلغة بشرية)

| رمز تقني قديم | المعنى البشري |
|---------------|----------------|
| src | المصدر — بدأت البيانات تدخل |
| collector | الجامع — جمعنا الاستهلاك |
| preprocessor | المعالج — نظّفنا أو عبّينا فجوة |
| rag | مساعد المعرفة — جاوب من المصادر |
| kb-policy | حارس السياسة — سمح أو منع |
| policy | السياسة — قرار الميزانية أو التنبيه |
| heatwave | سيناريو موجة الحر اكتمل |

إذا شفتِ كلمة VIOLATION في السجل القديم: معناها النظام منع الطلب. هذا نجاح للسيناريو الثالث، مو عطل.

## ترتيب عرض حي مقترح (دقيقة ونص)

1. افتحي About.
2. اضغطي SC-01 → قولي الجملة.
3. اضغطي SC-02 → وري السجل.
4. اضغطي SC-03 → وري المربع الأحمر / التنبيه.
5. وقفي. لا تضيفي أزرار زيادة إلا إذا سألوا.
